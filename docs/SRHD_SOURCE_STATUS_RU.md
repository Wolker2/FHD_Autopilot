# SRHD — состояние исходников на 2026-11-05

Проект: [FHD_Autopilot](https://github.com/Wolker2/FHD_Autopilot).

Архив на Google Drive: [FHD_Autopilot.rar](https://drive.google.com/file/d/16il21yWi4dgGJbyZlkY-WbhXc96iy3lQ/view?usp=drivesdk).

Исторический мод; пересборку и проверки маршрутов, безопасности посадок и ремонта вести отдельно от предыдущих исходников.

Этот документ **не** означает, что архив уже импортирован или протестирован. Исторические версии остаются на месте без изменений.

Обязательные требования ко всем последующим изменениям: поддержка обоих Rangers.exe при наличии EXE-зависимостей (автоматическое определение по хешу), рабочее TEST ↔ RELEASE через проверенный механизм, отсутствие запускающих .cmd и изменений папки игры, проверка сборки и тест в игре, отсутствие публичных паролей и токенов.
