## Состав

В ZIP **37 игровых файлов**: 3 DAT, 29 GI, 3 оригинальных TXT (`Main`, `Lang`, `CacheData`), `ModuleInfo.txt` и 1 **скомпилированный SCR**.

Папка `SOURCE` содержит:
- `ORIGINAL_TEXT/`: настоящие исходные TXT из установочного ZIP, без изменений
- `DAT_JSON/`: три DAT в редактируемом JSON; декодирование и обратное кодирование проверены побайтно
- `ORIGINAL_GI/`: все 29 оригинальных изображений
- `PNG/`: 29 редактируемых PNG, преобразованных из GI
- `ORIGINAL_SCRIPT/`: исходный игровой бинарный `.scr` без изменений (не исходный текст сценария)
- `ModuleInfo.utf8.txt`: редактируемый текст, исходная кодировка Windows-1251 сохраняется при сборке

`tools/build_source.py --verify` собирает чистый ZIP с точным SHA-256 оригинала. Изменять можно DAT_JSON, оригинальные TXT, PNG, оригинальные GI и ModuleInfo. Для преобразования PNG в GI требуется `srhd_modkit`. При отсутствии изменений `DIST` побайтно копирует оригинальный ZIP. При наличии изменений затрагиваются только соответствующие записи в ZIP. **Изменённые TXT сами по себе не компилируют DAT.**

Исходного текста компилированного SCR в архиве нет, поэтому восстановление его логики в виде редактируемого скрипта здесь не заявлено. Данный пакет сохраняет SCR бинарно.

**Статус TEST.** Проверки не подтверждают запуск игры, работоспособность автопилота, ремонта двигателя и совместимость с Navigator. Никаких игровых DLL или новых хуков не добавлялось; оригинальный мод не изменялся.
